## **E-Commerce React App**
**Description:**  
Built a small **E-Commerce** application using **React.js**, featuring product browsing, cart and wishlist management, theme and language switching, and advanced form handling.

**Key Features:**
- **Product Listing:** Fetch and display products using **Axios**.
- **State Management (Redux):** Manage Cart Counter, Theme (Light/Dark), and Language (Arabic/English) dynamically across the app.
- **Theme & Language Switching:** Users can toggle between **Arabic ↔ English** and **Light ↔ Dark** mode seamlessly.
- **Forms:** Implemented both **Native HTML Forms** and **React Hook Form** with **Zod Resolver** for validation.
- **Routing:** Navigation between product details, cart, wishlist, and authentication using **React Router**.
- **UI Components:** Responsive interface using **React-Bootstrap**.

**Technologies:** React.js, Redux, React Router, React Hook Form, Zod, React-Bootstrap, Axios, JavaScript
